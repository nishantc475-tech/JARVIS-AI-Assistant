# 🤖 JARVIS AI Assistant

A voice-controlled AI Assistant built using Python.

## Features
- 🎤 Voice Recognition
- 🔊 Text to Speech
- 🌐 Open Google
- ▶️ Open YouTube
- 🧮 Open Calculator
- 📝 Open Notepad

## Technologies Used
- Python
- SpeechRecognition
- pyttsx3
- Edge-TTS

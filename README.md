# ✨ Features

- 💬 AI Chat using Google Gemini
- 🎤 Voice Assistant
- 🔊 Text-to-Speech
- 📷 Camera AI
- 🖼 Image Analysis
- 🖥 Screen Analysis
- 📄 PDF Reader & Summarizer
- 🌦 Weather Information
- 📰 Latest News
- 🧠 Memory System
- 💾 Chat History
- ⚡ Fast Modern GUI
- 🌙 Dark Mode Interface

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/nishantc475-tech/JARVIS-AI-Assistant.git
```

```bash
cd JARVIS-AI-Assistant
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Run Project

```bash
python gui.py
```
